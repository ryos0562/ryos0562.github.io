プライバシーポリシー

最終更新日: 2026年11月18日

1. 対象と利用者

本ポリシーは、個人用ツール「Gmail-Secretary」（以下「本アプリ」）に適用されます。本アプリの利用者は開発者本人（GitHub: ryos0562）のみで、他のユーザーには提供していません。

2. 取得する情報と利用目的

本アプリは、Google API を通じて開発者本人の Gmail アカウントにアクセスし、メールの送信者・宛先・件名・本文・ラベルを読み取ります。利用目的は次のとおりです。

  • 受信メールを「返信が必要」「読んでおくべき」「不要」に仕分けし、本人に知らせること
  • 本人の指示に基づき、返信メールの下書きを本人の Gmail に保存すること
  • 処理済みのメールにラベルを付けること

本アプリはメールを送信しません。送信は本人が Gmail 上で行います。

3. 保存と外部送信

取得した情報は、本人の Gmail アカウント内（ラベル・下書き）以外には保存しません。仕分けと下書き作成のため、メールの内容が AI サービス（Anthropic 社の Claude）に送信され、処理されます。

4. 第三者提供

取得した情報を販売したり、広告に利用したり、第三者に提供したりしません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリが Google API から受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

6. アクセスの取り消し

本アプリへのアクセス許可は、Google アカウントのサードパーティ製アプリの管理画面からいつでも取り消せます。

Privacy Policy (English summary)

Gmail-Secretary is used only by its developer. It reads the developer's own Gmail messages solely to triage incoming mail, notify the developer, label processed messages, and save reply drafts on the developer's instruction. It never sends email. Data is not stored outside the developer's Gmail account, is not sold or shared with third parties, and is processed by an AI service (Anthropic's Claude) only for these purposes. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
