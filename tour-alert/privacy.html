プライバシーポリシー

最終更新日: 2026年11月18日

1. 対象と利用者

本ポリシーは、個人用ツール「TourAlert」（以下「本アプリ」）に適用されます。本アプリの利用者は開発者本人（GitHub: ryos0562）のみで、他のユーザーには提供していません。

2. 取得する情報と利用目的

本アプリは、Google API を通じて開発者本人の Google アカウントに次の範囲でアクセスします。

  • Gmail（読み取りのみ）: チケット販売サイトやファンクラブなどから届いたメールの送信者・件名・日時・本文を読み取り、ライブの発表やチケットの受付期間を見つけるために使います。メールの送信・削除・変更はしません。
  • Google カレンダー（本アプリが作成したカレンダーのみ）: 本アプリが作成した「TourAlert」カレンダーに、チケットの申込開始と抽選締切の予定とリマインドを登録・更新・削除します。それ以外のカレンダーには、読み取りも書き込みもしません。

3. 保存と外部送信

メールから抜き出したライブとチケットの情報（公演名・日程・会場・受付期間・申込ページの URL など）は、開発者本人の非公開の GitHub リポジトリに保存します。メールの本文そのものは保存しません。情報の抽出のため、メールの内容が AI サービス（Anthropic 社の Claude）に送信され、処理されます。

4. 第三者提供

取得した情報を販売したり、広告に利用したり、第三者に提供したりしません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリが Google API から受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

6. アクセスの取り消し

本アプリへのアクセス許可は、Google アカウントのサードパーティ製アプリの管理画面からいつでも取り消せます。

Privacy Policy (English summary)

TourAlert is used only by its developer. It reads (read-only) ticket-related emails in the developer's own Gmail to find concert announcements and ticket sale periods, and it creates, updates and deletes reminder events only in the "TourAlert" calendar that the app itself created; it does not read or write any other calendar, and it never sends, deletes or modifies email. Extracted concert and ticket information (not the email bodies) is stored in the developer's private GitHub repository. Email content is processed by an AI service (Anthropic's Claude) only for this purpose. Data is not sold or shared with third parties. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
